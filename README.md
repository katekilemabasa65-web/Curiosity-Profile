## 3. Seed Project Ideas

### Project: Public Healthcare Length-of-Stay & Readmission Explorer
* **Overview:** Working with a public healthcare or hospital quality dataset to investigate what patient characteristics or hospital features are most strongly linked to longer stays or readmissions[cite: 3].
* **Key Steps:**
  1. **Data Cleaning & Exploration:** Use Python (`pandas`) and SQL to clean inconsistent or missing records and test initial hypotheses[cite: 3].
  2. **Visualization & Storytelling:** Build simple charts and a dashboard to communicate findings to a non-technical audience[cite: 3].
  3. **Predictive Modeling (Extension):** Try a simple machine learning model to predict readmission risks, examining how well it performs and analyzing its limitations[cite: 3].

---

## 4. Skills to Grow

* **Technical Skill:** **Data Cleaning and Exploratory Data Analysis (EDA) using Python (Pandas) and SQL.**
  * *Why it matters:* Healthcare data is notoriously messy, incomplete, and inconsistent[cite: 3]. Mastering data cleaning is essential because any reliable analysis, dashboard, or predictive model depends entirely on the quality of the underlying data foundation.
* **Soft Skill:** **Translating Technical Insights for Non-Technical Stakeholders (Clinical Communication).**
  * *Why it matters:* As seen in successful implementations like Sepsis Watch, technical models only work if they integrate smoothly into human workflows[cite: 2]. A data professional must be able to listen to clinicians, understand hospital processes, and explain data findings in a clear narrative that care teams can act on with confidence[cite: 2].

## 5. Goals (30-Day + 6-Month)

* **Short-Term Goal (30-Day):** 
  * Complete a foundational exploratory data analysis project using a public healthcare dataset in Python (`pandas`) and SQL, focusing heavily on handling missing data and writing clean documentation on GitHub.
* **Mid-Term Goal (6-Month):** 
  * Build an end-to-end predictive model (such as a readmission or risk-scoring prototype) accompanied by an interactive dashboard, and write a non-technical summary report detailing how the insights could practically support hospital staff workflows.
